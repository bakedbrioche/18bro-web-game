# Critical contracts

- **C1 — deterministic simulation.** `dist/core.mjs`, route selection, choreography, and customization rules stay browser-DOM-free and testable with Node.
- **C2 — one editable source.** Modular files in `dist/` are authoritative. Standalone HTML is generated by `scripts/export-game.mjs`, never edited independently.
- **C3 — module serving.** Local development must serve `.mjs` as JavaScript. `npm start`/`npm run dev` use `server.mjs`; double-clicking `dist/index.html` is unsupported.
- **C4 — save compatibility.** Existing scores, chips, records, unlocked cosmetics, and settings survive schema changes through normalization/migration. Practice/debug runs never bank progress.
- **C5 — input parity.** Core play remains available through keyboard and touch; pause/resume, mute, reduced motion, and fullscreen remain operable where supported.
- **C6 — asset provenance.** Imported media and third-party code retain provenance/license notes. Do not embed unlicensed official artwork or fonts.
- **C7 — release gate.** A releasable change passes `npm run verify`. UI, rendering, input, or audio changes also pass the browser smoke flow and relevant desktop/mobile review.
- **C8 — bounded endless play.** Streamed scenery, crowds, traffic, and pooled entities stay bounded during long runs; route transitions do not create loads, dead ends, or collision gaps.

Changing a contract requires a `DEC-NNN` record, updated code/tests, and this file update in the same commit.
